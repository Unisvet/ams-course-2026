📖 The Story: The Silicon Cartographer

In Module 2, you unlocked the power of high-performance physics engines. In Module 3, you connected these simulators to cognitive models. But until now, the human has always been the bottleneck—analyzing the graphs, adjusting parameters, and clicking 'Run' again.

Today, we cross the threshold of autonomy. You will build the Silicon Cartographer. Your mission is to delegate the entire exploration of a JAX-accelerated Mandelbrot simulation to an agentic loop. The agent will act as an experimental scientist: starting from a global view, it will dynamically zoom in, analyze boundaries, calculate entropy, and refine its search coordinates.

We will implement this in three distinct phases: first, manual prompting to understand the bottleneck; second, native Tool Calling to automate the loops; and third, capsule packaging into a Gemma-Skill to build a reusable, modular agent.

⚡ Exercise 1: The Manual Cartographer (Pure Model)

Learning Objective: Experience the coordination overhead of manual human-in-the-loop parameter selection.

We start by running a JAX-accelerated Mandelbrot simulator. In this exercise, the agent only reasons in natural language, and the human is responsible for copying coordinates and running the code.

  1. Run Mandelbrot: Initialize the JAX Mandelbrot code provided in the starter notebook. Compute a global view at $c = -0.5, 0.0$ and zoom $1.5$.
  2. Prompt the Model: Write a prompt to the Gemini API (or local Gemma). Feed it the simulation output parameters (zoom, center coordinates, fraction of boundary pixels) and ask it to suggest the next coordinates to locate the "Seahorse Valley" ($c \approx -0.7436, 0.1318i$).
  3. Manual Feedback: Copy the model's suggested parameters, update your Python variables, execute the simulator, and feed the new metrics back to the model. Do this for 3 iterations.
📥 Deliverable

In your notebook, plot the final rendered region and document the coordinate history. Write a short paragraph explaining the structural limitations and latency bottle-necks of this manual parameter loop.

⚡ Exercise 2: Closed-Loop Tool Calling (Model + Tools)

Learning Objective: Implement declarative Function Calling schemas and construct an automated execution pipeline.

Now, automate the loop. You will declare the JAX Mandelbrot simulation as a tool that the model can invoke autonomously.

  1. Tool Definition: Define the JSON schema for your `run_mandelbrot_simulation` function. Declare it to the Gemini API using the `google-genai` SDK's tool registration mechanism.
  2. Execution Loop: Implement a ReAct runner in Python. Your script must:
    • Send the goal to the model: "Find coordinates of maximum complexity inside Seahorse Valley. Zoom at least 15,000x."
    • Catch the model's structured `function_call` response.
    • Extract parameters, call the local JAX simulator, and return the metrics (`Observation`) back to the model.
    • Repeat until the model decides to stop.
  3. Tracing: Print the model's Thoughts, Actions, and Observations to the terminal.
📥 Deliverable

Show the console output trace of your automated run (displaying Thoughts, Tool Calls, and Observations). Save and display the final zoomed fractal generated autonomously by the agent.

⚡ Exercise 3: Capsule Packaging: The Gemma-Skill (Model + Tools + Skills)

Learning Objective: Structuring agent architectures into modular, shareable, and self-contained Gemma-Skill units.

To make your autonomous engineer modular and reusable, package it into a standard **Gemma-Skill** capsule, conforming to the `google-gemma/gemma-skills` specification.

  1. Create Directory Structure: Inside your project repository, create a directory called `skills/mandelbrot_explorer`. Populate it with the required subdirectories: `tools/`, `scripts/`, and the main instructions file.
  2. Write SKILL.md: Author the `SKILL.md` file. It must include a YAML frontmatter declaring the skill's name and description (so the orchestrator can trigger it) followed by clear Markdown system instructions directing the model on how to analyze the boundary metrics.
  3. Deploy the Schema and Scripts: Place your JSON schema under `tools/mandelbrot_schema.json` and your JAX calculation python code under `scripts/mandelbrot_jax.py`.
  4. Bootstrap Loader: Write a Python bootstrap loader that dynamically registers this skill from the folder, parses the `SKILL.md` prompt, registers the tools, and initiates the autonomous loop.
📥 Deliverable

Submit your skill directory (`skills/mandelbrot_explorer/`) containing `SKILL.md`, the tool schemas, and the bootstrap loader. In your notebook, document how this encapsulation improves code maintainability and allows scaling to multi-agent architectures.
