Woche 11: Agent Development Environments (ADE) & Antigravity

In den vergangenen Wochen haben wir gelernt, wie wir mit dem Agent Development Kit (ADK) autonome, zustandsbehaftete Agenten programmieren und deren kognitiven Kreislauf steuern. Bisher liefen diese Agenten jedoch lokal in einem einfachen Skript oder einer Web-UI.

In der professionellen Softwareentwicklung reicht das nicht aus. Wenn mehrere Agenten zusammenarbeiten, Code auf einem System verändern oder parallel Hintergrundaufgaben ausführen, benötigt man eine kontrollierte, sichere und optimierte Umgebung. Eine Agent Development Environment (ADE) wie Google Antigravity stellt diese Schnittstellen, Sandboxes, Multi-Agenten-Orchestrierungen und Tracing-Werkzeuge zur Verfügung, um kognitive Agenten unter Produktionsbedingungen zu betreiben.

⚙️ 1. Was ist eine Agent Development Environment (ADE)?

Eine ADE erweitert die traditionelle integrierte Entwicklungsumgebung um agenten-spezifische Runtimes. Da Agenten kontinuierlich Entscheidungen treffen, Tools ausführen und Code schreiben, stellt eine ADE die notwendige Infrastruktur bereit:

  • Isolierte Sandboxes: Verhindert, dass fehlerhafter oder bösartiger Agenten-Code das Host-System beschädigt.
  • Kognitives Tracing: Protokolliert jeden Thought, jede Action (Tool Call) und jede Observation, damit Entwickler logische Fehlentscheidungen der Agenten analysieren können.
  • Multi-Agenten-Routing: Regelt die Kommunikation und Task-Delegation zwischen verschiedenen Subagenten.

🚀 2. Die 4 Oberflächen von Google Antigravity 2.0

Das im Mai 2026 veröffentlichte Antigravity 2.0 ist modular aufgebaut und verteilt sich auf vier spezialisierte Oberflächen, die alle auf demselben Core Agent Harness aufsetzen:

🖥️ Antigravity 2.0 Desktop App

Das eigenständige, agenten-zentrierte Kontrollzentrum. Entwickelt für parallele Task-Ausführung, Zeitplanung von Hintergrundprozessen und Multi-Agenten-Orchestrierung. Sie ist vom klassischen Code-Editor entkoppelt und ermöglicht die Steuerung ganzer Agenten-Swarms.

💻 Antigravity IDE

Ein hochoptimierter VS-Code-Fork. Hier arbeiten Entwickler direkt Code-Editierungen ab. Der Agent analysiert die Codebase und schlägt interaktive Änderungen über visuelle Diffs und Artifacts vor, die der Entwickler direkt übernehmen kann.

📟 Antigravity CLI

Ein leichtgewichtiges, in Go geschriebenes Terminal-Interface (TUI). Konzipiert für Entwickler, die Tastatur-zentrierte Workflows bevorzugen, sowie für Headless-Umgebungen über SSH auf Remote-Servern. Ersetzt die ältere Gemini CLI.

⚙️ Antigravity SDK

Das Programmier-Framework (Python, TypeScript, Go). Es entkoppelt die Kognitions- und Tool-Logik vom Frontend. Entwickler nutzen das SDK, um Agenten direkt in ihre eigenen Apps einzubetten oder komplexe Automatisierungs-Pipelines aufzusetzen.

🔬 3. Literature Search mit DeepMind Science-Skills

KI-Agenten benötigen Zugriff auf vertrauenswürdiges, aktuelles Fachwissen, um Simulationen korrekt zu konfigurieren. Google DeepMind stellt dafür das Science-Skills Ökosystem bereit. Dies sind modular aufgebaute Werkzeuge zur Abfrage akademischer Datenbanken:

🧬 Unterstützte Wissenschafts-Kataloge

  • arXiv: Zugriff auf über 2,4 Millionen Preprints aus Physik, Mathematik und Informatik. Agenten können Abstracts analysieren und Volltext-PDFs abrufen.
  • OpenAlex: Ein globaler Katalog wissenschaftlicher Arbeiten, Autoren und Institutionen. Optimal für Zitationsanalysen und DOI-Abfragen.
  • PubMed & BioRxiv: Fokus auf biomedizinische Daten, Genomik und klinische Studien.

Im Problem Set 11 bauen Sie einen Scholar-Prime Agenten, der diese Skills nutzt, um autonom thermodynamische Simulationsparameter für Reaktoren aus echten wissenschaftlichen Publikationen zu recherchieren, zu parsen und als strukturierte Daten zu speichern.

Für ein vertieftes technisches Verständnis von Agent Development Environments (ADEs), dem Google Antigravity-Ökosystem, dem Model Context Protocol (MCP) und den DeepMind Science-Skills empfehlen wir die folgenden offiziellen Dokumentationen, Code-Repositories und Forschungspapiere:

⚡ Google Antigravity & Agent Runtimes

  • Woche 11 Cinematic Explainer Video (YouTube): Ein audiovisueller Deep Dive in Agent Development Environments (ADE), die 4 Oberflächen von Google Antigravity 2.0 (App, IDE, CLI, SDK) und das Model Context Protocol.
    🔗 youtu.be/vvZFvvl3LJA
  • Google Antigravity Developer Portal: Offizielle Plattform und Dokumentation für Google Antigravity 2.0 – Googles agenten-zentriertes Entwurfs-Ökosystem bestehend aus Desktop App, VS-Code-Fork IDE, Terminal CLI (Go) und Programmier-SDK.
    🔗 antigravity.google
  • Google Agent Development Kit (ADK) Core Repository: Das quelloffene Python-Repository für ADK und das Antigravity Agent Harness. Enthält Kernabstraktionen (`Agent`, `Workflow`), Sandboxing-Mechanismen, Tracing-Hooks und den Web-UI-Runner.
    🔗 github.com/google/adk-docs
  • Google ADK & Antigravity Sample Garden: Kuration von Beispiel-Multi-Agenten-Systemen, hierarchischen Swarm-Architekturen und Tool-Binding-Mustern für die Praxis.
    🔗 github.com/google/adk-samples

🔬 DeepMind Science-Skills & Akademische Datenbanken

  • Google DeepMind Science-Skills Repository: Offizielles Open-Source-Repository modularer Agenten-Werkzeuge (arXiv, OpenAlex, PubMed, UniProt, ChEMBL) zur automatisierten Wissenschafts-Recherche.
    🔗 github.com/google-deepmind/science-skills
  • OpenAlex Global Research Index: Ein freier, globaler Index über 250 Millionen wissenschaftliche Publikationen, Zitationsgraphen und Autoren-Profile mit REST-API für Agenten-Abfragen.
    🔗 openalex.org
  • arXiv Open-Access Preprint Server: Offene Datenbank für über 2,4 Millionen Arbeiten aus Informatik, Physik und Mathematik mit maschinenlesbarer Schnittstelle zum PDF- und Abstract-Parsing.
    🔗 arxiv.org

🌐 Agenten-Standards, MCP & Sandboxed Execution

  • Model Context Protocol (MCP) Spezifikation (AAIF): Der von Anthropic initiierte und der Agentic AI Foundation (Linux Foundation) übergebene Open-Standard zur standardisierten Anbindung von KI-Agenten an externe Tools und Datenbanken.
    🔗 modelcontextprotocol.io
  • Hugging Face Smolagents (Code-Centric Agents): Pionier-Framework zur direkten Python-Codeausführung durch Agenten in isolierten Sandboxes statt starrer JSON-Toolcalls.
    🔗 github.com/huggingface/smolagents
  • LangGraph Multi-Agent Orchestration: Zustandsbehaftetes Framework zur Modellierung zyklischer Multi-Agenten-Graphen mit integrierten Human-in-the-Loop Schnittstellen.
    🔗 github.com/langchain-ai/langgraph
  • OpenAI Agents SDK & Guardrails: Leichtgewichtiges Multi-Agenten-Framework mit automatischem Hand-off Routing, Tracing und Sicherheits-Guardrails.
    🔗 github.com/openai/openai-agents-python
