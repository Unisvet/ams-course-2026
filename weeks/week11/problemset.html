📖 The Story: Awakening the Scholar

Architects of the Neo-Simulacrum, your engineering agent Observer-Prime is now autonomous in its control loops, but it lacks external knowledge. It only knows what is in its pre-trained weights or what you pass to it manually. To model complex physical systems, it must acquire knowledge from the frontier of human science.

Today, you will build Scholar-Prime—a specialized literature retrieval and parameter extraction agent. Using the newly released Google DeepMind Science-Skills, your agent will connect to global academic databases, search for papers on reactor materials, download the publications, and programmatically parse them to extract thermal conductivity matrices.

⚡ Exercise 1: Setting up the Science Skills

Learning Objective: Cloning the science-skills repository, installing dependencies, and verifying the CLI tools.

Before an agent can search databases, it must have the appropriate adapters. DeepMind's science-skills repository contains standardized schemas and CLI handlers for major archives.

  1. Clone the Repository: Clone the official Google DeepMind repository into your project directory: 
    git clone https://github.com/google-deepmind/science-skills.git
  2. Sync the Environment: Navigate to the science-skills/skills/literature-search-openalex folder and use uv to lock and sync the dependencies: 
    uv sync
  3. Execute a Test Query: Run the OpenAlex CLI tool to resolve a researcher's identity (e.g., Geoffrey Hinton) and fetch their ID details: 
    uv run scripts/openalex_cli.py resolve authors "Geoffrey Hinton"
📥 Deliverable

Submit the console output of the resolve authors command, showing the resolved OpenAlex author ID.

⚡ Exercise 3: Automated Search & Downloader (Tool Binding)

Learning Objective: Exposing literature search CLI scripts as python tools to the agent.

  1. Write the Wrapper: Create a Python function search_arxiv(query: str, max_results: int = 5) -> str. Inside, execute the arXiv search script from the cloned science-skills repository and capture its output.
  2. Bind the Tool: Expose this function to scholar_prime in its tools list.
  3. Test the Run: Restart your ADK web UI and prompt the agent:

    "Scholar-Prime, search arXiv for papers on 'thermodynamic simulation parameters for advanced fission reactors'. Identify the most relevant paper and summarize its abstract."

📥 Deliverable
