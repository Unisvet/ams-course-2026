⚡ Exercise 1: Bootstrapping the Core (ADK Setup & `uv` Environment)

*Learning Objective: Integrating the ADK into our modern `uv` workspace, safely managing environment variables, and utilizing the ADK CLI.*

Before an entity can think, it needs a sanctuary. The ADK requires a specific, modular file structure to auto-discover your agents. We will leverage our modern uv dependency manager to securely lock the ADK into our pyproject.toml.

  1. The Installation: Ensure you are in your project directory in the terminal. Use uv to instantly resolve, install, and add the framework to your project configuration: 
    uv add google-adk
  2. The Vault of Secrets: Create a .env file in the root of your project directory. Add your Gemini API key: 
    GOOGLE_API_KEY="your_actual_key_here"
    (Crucial: Ensure .env is added to your .gitignore!)
  3. The Scaffold: Use the built-in ADK CLI to generate your agent workspace safely within your isolated uv environment: 
    uv run adk create cognitive_core
    Notice how the ADK auto-generates a folder named cognitive_core containing an __init__.py and an agent.py.

⚡ Exercise 4: Arming the Architect (Tool Binding & The Autonomous Loop)

*Learning Objective: Registering custom Python functions as tools within the ADK architecture to enable the autonomous Perceive-Think-Act loop.*

An agent without tools is just a philosopher. Let's give it the power to alter our simulated reality.

  1. The Physics Tool: Above your Agent definition in agent.py, write a simple pure Python function (complete with accurate Type Hints and a Docstring—the ADK relies on these to teach the Gemini model exactly how to use the tool!): 
    def adjust_reactor_temperature(delta_t: float) -> str:
    """
    Adjusts the core temperature of the reactor.
    Args:
        delta_t: The amount to increase or decrease the temperature in Kelvin.
    """
    new_temp = 300.0 + delta_t
    if new_temp > 350.0:
        return f"WARNING: Reactor overheated at {new_temp}K! Core breach imminent."
    return f"Success: Reactor stabilized at {new_temp}K."
  2. The Binding: Pass your function to the agent using the tools=[adjust_reactor_temperature] parameter inside your Agent instantiation.
  3. The Autonomous Loop: Restart the adk web server (stop it with Ctrl+C in the terminal, then run uv run adk web again). In the Web UI, command the agent:

    "Observer-Prime, the reactor needs to be heated. Try increasing the temperature by 80 degrees. If a warning occurs, you must autonomously calculate a safer parameter and retry the tool until you achieve a 'Success' status."

  4. Observe the Magic: Watch the UI as the ADK triggers the **Perceive ➔ Think ➔ Act ➔ Check** loop. The agent will call the tool with 80, receive the WARNING, think about the failure, and autonomously call the tool again with a smaller number until it succeeds.
