Theoretical Introduction

Week 10: Introduction to the Agent Development Kit (ADK)

So far, we have primarily used Foundation Models as callable functions in our Python scripts. We manually maintained chat histories, parsed JSON responses, and programmed complex "Thought-Action-Observation" loops (ReAct) so the model could use tools. Every workflow was rigid and had to be dictated by us in detail.

With Agentic Engineering, this paradigm changes fundamentally: we move from dictation to delegation. The developer uses a modern environment (e.g., the Antigravity IDE) and describes the goal to the AI agent in natural language ("Vibe Coding"). The agent plans autonomously, writes code, orchestrates sub-agents, tests results in a safe sandbox, and corrects errors independently. The Google Agent Development Kit (ADK) provides the code framework to build exactly such autonomous, stateful agents in Python.

📦 1. Installation and Setup with uv

The ADK integrates seamlessly into modern Python workflows. Since we focus on high performance and reproducible environments in our course, we use uv instead of the legacy pip. We add the ADK directly to our project: 

uv add google-adk

We store sensitive keys securely in a .env file, which the ADK reads automatically on startup: 

GOOGLE_API_KEY="your_api_key_here"

With the integrated command-line interface, we can then immediately generate a runnable agent project with the correct structure (__init__.py and agent.py): 

uv run adk create my_first_agent

🧬 2. Anatomy of an Agent (agent.py)

An agent is defined in the ADK via four central parameters:

🤖 1. model

The cognitive LLM brain. We use gemini-3.5-flash for extreme latency advantages and logical strength.

🏷️ 2. name

The unique system name (e.g., observer_prime) for internal routing within the ADK system.

📝 3. description

Capability description. Essential in multi-agent systems (MAS) for autonomous task routing.

📜 4. instruction

The system prompt. Defines personality, scope of action, rules, and detailed knowledge.

Python implementation example:
from google.adk.agents.llm_agent import Agent
93: 
94: root_agent = Agent(
95:     model='gemini-3.5-flash',
96:     name='reactor_overseer',
97:     description='A specialized agent for system simulations.',
98:     instruction='You are a precise engineer. Monitor parameters and use tools for stabilization.'
99: )

🔄 3. State Tracking & Memory Management

Traditional API calls are stateless – the model forgets everything after each response. The ADK solves this problem through implicit memory management. The system automatically saves the state of the conversation and the results of function calls. The integrated Perceive ➔ Think ➔ Act ➔ Check loop ensures that the agent recognizes errors in tool calls, reads the error message from its memory, and independently tries new parameters without your program crashing or requiring manual intervention.

🖥️ 4. Execution and Testing (CLI vs. Web)

The ADK provides ready-made interfaces by default to interact with agents immediately without having to build your own frontend:

📟 Interactive CLI Shell

With the command uv run adk run cognitive_core, you start the agent in a text-based interactive console. Perfect for quick, lean tests directly from the terminal.

🌐 Local Web UI

The command uv run adk web starts a local server (defaults to http://localhost:8000). In the browser chat, you can see the agent thinking live (Chain of Thought) and which tools it calls – the ideal tool for visual debugging!

📖 Literature & Resources

For a deeper scientific and practical understanding of the Agent Development Kit (ADK) and modern agentic engineering, the following publications and official resources are highly recommended:

  • Google Agent Development Kit (ADK) Documentation The official developer documentation and integration guide for building, orchestrating, and evaluating multi-agent systems with Google's ADK. adk.dev
  • Agent Garden (google/adk-samples) Official Google repository containing sample agents, design patterns, and boilerplate code demonstrating the use of ADK. github.com/google/adk-samples
  • Google ADK Python Core Repository The open-source Python implementation of ADK containing core classes (`Agent`, `Workflow`), execution engines, and local Web UI runner. github.com/google/adk
  • The Rise of "Vibe Coding" & Agentic Workflows (Karpathy, Feb 2025) – Explores the paradigm shift from manual programming to delegation, intent specification, and autonomous agent loops. Andrej Karpathy's Vibe Coding Essay on X
  • Anthropic Research: Building Effective Agents (Anthropic, 2024) – Comprehensive research guide on agentic design patterns, distinguishing workflows from dynamic agents, orchestrator-worker architectures, and evaluator-optimizer loops. anthropic.com/research/building-effective-agents
  • ReAct: Synergizing Reasoning and Acting in Language Models (Yao et al., 2022) – The seminal research paper establishing the interleaving of Chain-of-Thought reasoning with active environment tool execution in ADK agents. arXiv:2210.03629
  • Model Context Protocol (MCP) Specification The open-source protocol for linking external data sources, files, and tools securely to LLM agents. modelcontextprotocol.io
